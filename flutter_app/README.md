# ГрГМУ Расписание — Flutter

Flutter-версия приложения для расписания ГрГМУ.

После установки Flutter SDK:

```bash
cd flutter_app
flutter pub get
flutter analyze
flutter run
```

Проект загружает зависимые ASP.NET-списки, проходит недели, сортирует даты по возрастанию, сохраняет расписание локально и показывает дни свайпом.
