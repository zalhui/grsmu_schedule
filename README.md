# ГрГМУ Расписание

Flutter-приложение для выбора группы и просмотра расписания ГрГМУ.

Исходный код находится в каталоге `flutter_app`.

```bash
cd flutter_app
flutter pub get
flutter analyze
flutter run
```

Сборка debug APK:

```bash
flutter build apk --debug
```

Приложение получает факультеты, формы обучения, курсы, группы и расписание с сайта университета, загружает недели и сохраняет расписания локально.
