# ГрГМУ Расписание

Flutter-приложение для выбора группы и просмотра расписания ГрГМУ. Исходный код находится в каталоге `flutter_app`.

Инструкции по настройке Flutter и Android Studio, запуску приложения и сборке APK находятся в [BUILD.md](BUILD.md).

Приложение загружает факультеты, формы обучения, курсы, группы и расписание с сайта университета. Расписания сохраняются локально.
